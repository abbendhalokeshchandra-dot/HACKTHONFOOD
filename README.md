# FoodRescue Website

Deployment-ready frontend prototype.

## Local
Open `index.html` or run it through VS Code Live Server.

## GitHub
Upload all files in this folder to a repository.

## Netlify / Vercel
Import the GitHub repository. Build command: none. Publish directory: `/`.

## Features
- Food donation form
- Offline LocalStorage saving
- Online/offline status
- PWA service worker
- Food availability cards
- Responsive design
- Impact dashboard

For production, connect authentication, database, maps, NGO accounts, notifications and server-side synchronization to a backend such as Firebase/Supabase/API.
